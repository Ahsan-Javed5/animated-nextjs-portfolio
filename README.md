# 🚀 Modern Animated Developer Portfolio

A sleek, responsive, and high-performance developer portfolio built with **Next.js**, **Tailwind CSS**, and modern UI animations. Designed for developers, software engineers, and creators looking for a modern, production-ready portfolio template.

👉 **Live Demo:** [https://animated-nextjs-portfolio-swart.vercel.app](https://animated-nextjs-portfolio-swart.vercel.app)

---

## 🌟 Key Features

- **🎨 Modern Aesthetic:** Vibrant gradient design with smooth interactive UI micro-interactions.
- **⚡ High Performance:** Built using Next.js App Router for blazing fast loading speed and SEO optimization.
- **✨ Smooth Animations:** Fluid page transitions and interactive hover effects.
- **📱 Fully Responsive:** Clean layout customized for mobile, tablet, and desktop views.
- **🛠 Easy Customization:** Well-structured codebase designed for quick personal tweaks.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)

---

## 🚀 Quick Start

Follow these steps to run the project locally:

```bash
# 1. Clone the repository
git clone [https://github.com/Ahsan-Javed5/animated-nextjs-portfolio.git](https://github.com/Ahsan-Javed5/animated-nextjs-portfolio.git)

# 2. Navigate to the project directory
cd animated-nextjs-portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
